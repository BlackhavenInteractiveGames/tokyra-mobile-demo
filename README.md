# TOKYRA – EVERY LIFE HAS A STORY

Single Street mobile 3D prototype.

## Start
GitHub Pages serves `index.html` from the repository root. The demo needs an internet connection for Three.js and the externally hosted 3D models.

## Controls
- Mobile: on-screen touch controls.
- Desktop: WASD / arrow keys; E to enter or exit the car.

TOKYRA and KAIRO S1 are fictional project names.
