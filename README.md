# TOKYRA – EVERY LIFE HAS A STORY

Single Street mobile 3D demo.

## Required files — all in the repository root
- `index.html`
- `character.glb` — Amara, a textured adult female 3D model (CC0)
- `car.glb` — generic 1990s Japanese-style sports coupe (CC0)

The GLB models are loaded from the same GitHub Pages origin as the game. This avoids cross-origin restrictions and third-party asset-host availability.

## Controls
- Mobile: on-screen buttons.
- Desktop: A/D or arrow keys; W/up to accelerate, S/down to brake, E/Enter to enter or exit the car.

Three.js is loaded from jsDelivr, so an internet connection is required.

## Asset sources and licenses
- Character (CC0): https://www.innerscene.com/tools/library/3d-parts/amara-3d-person-standing-office-2a16c294
- Car (CC0): https://www.innerscene.com/tools/library/3d-parts/generic-1990s-japanese-style-sports-coupe-ace64592

Save the downloaded character model as `character.glb` and the car model as `car.glb`. Upload both to the repository root, next to `index.html`.

TOKYRA and KAIRO S1 are fictional project names.
